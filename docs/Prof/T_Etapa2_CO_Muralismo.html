🧩 Gramática exigida

1. El pretérito indefinido → les faits, les actions terminées et datées

On l'emploie pour raconter l'histoire du muralisme : ce qui s'est passé, une fois, à un moment précis (en 1921, después, a partir de ese momento).

sujet-AR (comisionar)-ER / -IR (asumir)
él / ellacomisionóasumió
ellos / ellasusaronredescubrieron
  • Dans la vidéo : inició, comisionó, asumió, comenzó, surgió, usaron, redescubrieron, utilizaron.
  • ⚠️ L'accent est obligatoire à la 3ᵉ personne du singulier : comisionó (il commanda) ≠ comisiono (je commande).
  • Verbes irréguliers de la vidéo : tener → tuvo / tuvieron · ser → fue / fueron · convertirse → se convirtió / se convirtieron (e → i).

2. El imperfecto → le contexte, la situation de l'époque

On l'emploie pour dire comment était le Mexique, ce que les gens voulaient ou ce qui durait.

sujet-AR (necesitar)-ER / -IR (querer, haber)ser
él / ellanecesitabaquería · habíaera
ellos / ellasnecesitabanqueríaneran
  • Seulement trois irréguliers : ser (era), ir (iba), ver (veía).
  • Después de la Revolución, México necesitaba un arte nacional y muchos mexicanos no sabían leer.

⚠️ Le bon réflexe : un fait daté → indefinido (En 1921, Vasconcelos comisionó murales) ; une situation ou une intention → imperfecto (porque quería un arte para el pueblo). Les deux vont souvent ensemble dans la même phrase.

3. Los posesivos su / sus

  • su + nom singulier, sus + nom pluriel = son, sa, ses / leur, leurs : su historia, sus murales.
  • su s'accorde seulement en nombre avec l'objet possédé, jamais avec le possesseur : los muralistas y su arte (leur art).
  • Pour nous : nuestro / nuestra / nuestros / nuestras : nuestro párrafo, nuestra presentación.
